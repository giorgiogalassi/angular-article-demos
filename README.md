# Angular Forms – Data Flow and Working with Inputs (Part 2)

This StackBlitz contains all the interactive examples used in **Part 2** of the Angular Forms series.

The goal of this playground is to demonstrate how **data flows between the UI and the model** when working with different Angular form approaches:

- Template-driven Forms
- Reactive Forms
- Signal Forms (experimental)

## What you’ll find here

- Input handling for text, numbers, checkboxes, radio buttons, dates, and selects
- Differences between synchronous, asynchronous, and reactive data flows
- Programmatic reading and updating of form values
- Side-by-side demos focused on runtime behavior, not API trivia

## How this relates to the article

This project is meant to be explored **alongside the article**, not as a standalone tutorial.

If you’re reading the article on Medium or Dev.to, you can use this playground to:

- interact with the examples
- inspect runtime behavior
- experiment with small changes

➡️ Read **Part 2 – Data Flow and Working with Inputs** to follow the full explanation.

## Notes

- Signal Forms are still experimental and may change in future Angular versions.
- For production use cases requiring long-term stability, Reactive Forms remain the safest choice.
